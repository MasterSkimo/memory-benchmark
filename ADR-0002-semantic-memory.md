# ADR-0002 — semantic memory pilot

Status: pilot decision recorded; production adoption deferred for review.

BENCH-0002 executed a frozen 80-note FR/EN corpus across ten org/project scopes. Five native Luna implementation streams built isolated V2 code. Qdrant used a reproducible, genuinely learned local 384D bilingual encoder and sparse RRF; Basic Memory ran real stdio MCP through a custom façade; Cognee's canonical offline tokenizer and actual native add/dataset persistence were repaired. Graphiti's shared encoder runs, but genuine graph extraction and Cognee cognify remain blocked without a provisioned capable local extraction LLM.

The 40-question R pilot measured macro source recall@5 of **96.9% Basic Memory**, **84.4% direct Markdown** and **73.4% Qdrant hybrid**, over 32 answerable questions. Median adapter latency was **1778.798 ms**, **1.525 ms**, and **1.574 ms**, respectively. Basic Memory's path starts MCP and synchronizes/indexes a private copy on every search. This cost is implementation-specific. Qdrant's current-only filter returned zero obsolete hits but prevents historical source recall. Direct returned 23 obsolete hits and Basic Memory eight; historical questions are exempt when their old source is required. No cross-scope result was observed in the 120 R result sets. All eight negative retrieval questions returned hits for every engine.

This run does not demonstrate a semantic retrieval advantage. The small neural model has 323 word tokens and 40 authored translation pairs; it is not representative of a pretrained multilingual sentence model. The official pretrained distribution was denied by the managed proxy. Dense-only and fusion/obsolete-filter ablations were not run. R Pareto points are direct Markdown and Basic Memory; Qdrant is dominated on measured recall/median latency in this tiny pilot. These findings do not select a universal engine.

The E lane made at most 20 native answer attempts per runnable engine: 59 final submissions and one unrecovered direct attempt. Prompt provenance is verified for only 38 submissions (12 direct, 13 Qdrant, 13 Basic). Eighteen prompts were not captured; three captured prompts had wrong question/scope assignments. Those are unscored, not fabricated measurements. On the ten common verified/unassisted questions, component/citation scores are 90% direct, 90% Qdrant and 100% Basic, with mean wrapper counts 3.4, 4.1 and 4.5. This subset covers temporal/revision/negative questions only. Full-20 E quality is **null/INCOMPLETE**. Schema/cwd/capability failures, one extra hint, an early corrected response mapping, unrestricted native tools and language deviations make the E comparison exploratory.

Native input/cached/output/reasoning tokens, native tool counters, immutable served snapshots and subscription spend were not exposed. They remain null. Wrapper calls, payload bytes and local encoder input units are separate observations and do not establish native token savings. Ingest factories and own/child CPU/I/O are captured; RAM is process high-water RSS, physical cache is uncontrolled, Basic Memory child peak RAM and model-training resources are unavailable. Amortization is arithmetic over measured factories, not execution at 200/2k/20k queries.

Decision: retain scoped Markdown as the reference and defer production memory selection. Keep the verified Basic Memory MCP and Cognee tokenizer/add repairs. Retain Qdrant's real neural implementation as a research candidate, with the model's limited training explicitly disclosed. Do not describe blocked Graphiti/Cognee graph paths as exercised or recommend graph adoption from this evidence. No validated native token/call savings are claimed.

The deterministic native_prompt.py preparation repair now checks question/session IDs, principal and capability, uses an absolute client path and includes exact JSON schema. Its integration test passed after this pilot; the repaired protocol was not used for additional sessions. A further pilot should provision approved pinned pretrained embeddings and a capable local extraction LLM, validate the entire native dispatch path before freezing, capture authoritative prompts/finals atomically, and use a withheld dataset with an actual access boundary. Review this pilot before any rerun, full benchmark or load test.

Reproducibility: results/v2/run-manifest.json, COMPARISON.md, prompt-audit.json, raw R/E traces, dependency locks, model hashes/training recipe, artifact-sha256.json and validation.json. 30 V2 integration checks passed; one Graphiti integration class was skipped. Nine restored offline tests also passed. All 189 V1 tracked files are byte-identical to commit 94a2a4beacf90f6a9640ecd43ebae8b8c9e7a708. The V2 branch originally deleted those files; they are restored unchanged.

The pilot has stopped. No full benchmark, load test, nested authenticated Codex CLI, external paid inference or network-policy bypass was executed.
