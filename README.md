# Agentic Memory BENCH-0001 — Codex Cloud

Benchmark **Basic Memory, Cognee, Graphiti, Qdrant hybrid and Luna direct Markdown**. Compare grounded accuracy, citations, Codex token consumption, tool calls, cold ingestion, isolation and latency.

## Launch in Codex Cloud

1. Connect **MasterSkimo/memory-benchmark** to Codex Cloud.
2. If Codex offers an environment setup script, set `bash scripts/cloud-setup.sh`.
3. Create a task using [PROMPT-CODEX-CLOUD.md](PROMPT-CODEX-CLOUD.md).
4. Have SOL delegate the five candidate implementations to Luna workers where multi-agent delegation is supported.
5. Review the **20-question pilot**, then explicitly authorize further testing.

## Offline bootstrap

```bash
bash scripts/cloud-setup.sh
python3 -m unittest discover -s tests -v
```

Python 3.11+ is sufficient for offline setup. Vendor engines require their own dependencies; Codex should verify network, Docker and package availability before trying to install them. Nothing assumes nested Codex CLI login.

## Trust boundary

`fixtures/vault/`, `fixtures/questions_public.jsonl`, `fixtures/questions_public_pilot.jsonl` are generated locally from `benchkit/cloud_fixtures.py`. The oracle is never generated by setup or committed. After obtaining candidate traces, a **separate trusted evaluator** can run:

```bash
# In a distinct evaluator workspace; do not mount this output into candidate workspaces.
python3 -m benchkit.trusted_evaluator \
  --questions fixtures/questions_public_pilot.jsonl \
  --oracle-output /secure/evaluator/oracle.jsonl \
  --traces /secure/evaluator/candidate-end-to-end.jsonl \
  --score-output /secure/evaluator/score.json
```

The oracle algorithm is transparent and synthetic; genuine confidentiality requires process/filesystem separation plus human-reviewed real-world holdout tests. A worktree is not a security boundary.

## Validity and limitations

- The original RFC and scientific benchmark protocol are in the repository. The **cloud-0.2 fixtures** are regenerated deterministically and their manifest hash must be frozen; they are not byte-identical to the earlier local ZIP fixtures.
- Some benchmark candidates require local embedding or extraction LLMs. Do not consume paid API credits without authorization. Mark an unsupported arm BLOCKED.
- Token counters from native Codex Cloud are only reported when the environment exposes them. Missing values are `null`, never estimated as measured.
- Codex Cloud may not expose five concurrent Luna workers or a nested authenticated Codex CLI. Actual concurrency and identities must be recorded.
- No vendor performance measurements or five-agent runs have been produced in this repository yet.
