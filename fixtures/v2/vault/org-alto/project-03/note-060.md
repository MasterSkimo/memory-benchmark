# Révision du déploiement — Silex

Version v2-r2, approuvée le 2026-07-15 : avant toute mise en production de Silex, obtenir la validation de l’équipe Cobalt, puis utiliser une bascule progressive. La version v2-r1 demandait seulement une validation individuelle; cette ancienne règle est retirée. Current approval and rollout must both follow this revised instruction.
