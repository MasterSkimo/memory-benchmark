# Révision du déploiement — Emeraude

Version v2-r2, approuvée le 2026-07-15 : avant toute mise en production de Emeraude, obtenir la validation de l’équipe Ambre, puis utiliser une double exploitation vérifiée. La version v2-r1 demandait seulement une validation individuelle; cette ancienne règle est retirée. Current approval and rollout must both follow this revised instruction.
